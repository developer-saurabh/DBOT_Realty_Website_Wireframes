# DBOT Realty — Website Wireframe Prototype

A responsive, clickable, low-to-mid fidelity website wireframe built from the supplied:
- DBOT Realty Website — Sitemap, Flow & Page Spec
- DBOT Corporate Deck (2026)
- DBOT ESG & Advisory Services Profile (2026)
- DBOT Realty presentation deck

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Use the navigation to explore the page templates. No build step or package install is required.

## Included page routes
- Home
- Services overview + six service-area detail templates
- Sectors overview + sector detail template
- Who we serve overview + client-type detail template
- Projects listing with category filters + project case-study detail template
- Insights listing with category filters + article detail template + gated report form modal
- About overview, Leadership, Our Presence
- Careers listing + application form
- Contact form + registered office map placeholder
- DBOT Technologies destination placeholder

## Prototype interactions
- Responsive mobile navigation
- Project and insight filters
- Share/copy link action on service and article pages
- Gated research report modal
- Demo enquiry, newsletter and job application form feedback
- Cookie consent banner

## Design direction
- Corporate editorial style: deep navy, restrained gold and green accents, white space, large serif headlines.
- Architecture and project imagery are represented by labelled placeholders so the design team can replace them with approved DBOT photography.
- Header, footer, navigation, service order and page templates follow the website page spec.

## Important content and launch decisions
The prototype deliberately flags rather than invents unresolved items:
- Final service-to-area grouping and service list confirmation.
- DBOT Technologies destination URL.
- Which 6–10 project case studies may be published, and which must be anonymised.
- Written permission for client logos and testimonials.
- Correct built-up area figure and unit (the website spec says the unit needs confirmation; corporate deck reports sqm).
- Research report open vs gated policy.
- Careers workflow: email form vs applicant tracking system.
- CMS, hosting, existing-site URL redirects, city office addresses and contact details.
- The spec proposes client, employee and public logins in phases; login portals are not implemented in this launch wireframe.

## Implementation notes
This is a front-end wireframe prototype, not a production website. Forms do not submit data, the map is a placeholder, and CMS/CRM/email/analytics integrations are not connected. Replace sample project cards, roles, articles and placeholder contact information with approved content before development.
